# EdgeQuill

EdgeQuill provides cloud-based, real-time data processing for scalable applications, utilizing an auto-scaling orchestrator and dynamic scheduler.

With EdgeQuill, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/EdgeQuill.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
